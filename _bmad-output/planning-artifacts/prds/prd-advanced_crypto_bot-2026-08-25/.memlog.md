- (decision) Create a replacement PRD rather than patching the legacy AutoTrade because canonical decision and lifecycle integrity failed in production dry-run evidence.
- (decision) Use Fast Path with high-stakes rigor; real trading remains excluded until evidence-based promotion and explicit user approval.
- (assumption) Treat the investigation, handoff, architecture roadmap, and prior technical research as the initial brain dump because the user asked to resume from that checkpoint.
- (decision) Define the product around one canonical decision, fill-based accounting, persisted policy state, and a shared simulator because the legacy split paths caused confirmed ghost positions.
- (decision) Use calibrated abstention and cost-aware hysteresis; change detection governs risk but does not generate alpha or auto-promote.
- (decision) Keep the MVP single-operator, spot-IDR, DRY RUN, with one interpretable Champion and one isolated Challenger; live trading requires a separate PRD.
- (assumption) Initial promotion thresholds (30 days, 100 independent trades, PF 1.20, DD 10%, DSR 95%, PBO 10%) are governance proposals requiring user confirmation and preregistration.
- (decision) Use a dynamically eligible universe across spot-IDR pairs, not only the most liquid subset; each pair must still pass data, execution-cost, history, and tradability gates.
- (decision) Primary horizon spans intraday swing through multi-day, evaluated as separately versioned experiments/horizons.
- (decision) Legacy strategy may become Champion only if it passes the same locked evidence and promotion gates as every challenger.
- (event) Drawdown instruction remains ambiguous: requested maximum, but an explicit hard percentage is required because interpretation changes portfolio risk.
- (decision) Set hard maximum portfolio drawdown to 10% from equity peak; breach blocks new entries while exits, cancels, reconciliation, and monitoring remain active.
- (decision) Set maximum notional for a single Position to 10% of portfolio equity at decision time; liquidity, stop distance, and uncertainty may only reduce it.
- (decision) Set maximum total open portfolio exposure to 40% of equity; correlation, liquidity, and uncertainty gates may only reduce it.
- (decision) Set maximum daily loss to 2% of cash-flow-adjusted start-of-day equity, including realized and unrealized P&L; breach blocks entries until the defined next session while exits and reconciliation remain active.
- (decision) Set maximum risk-at-stop to 0.5% of equity per trade.
- (change) Reviewer hardening added action-state legality, operational drawdown/kill/reconciliation semantics, dynamic-universe contracts, simulator fidelity tiers, replay determinism, immutable evidence enforcement, brownfield boundaries, and separate platform/strategy/live gates.
- (decision) Define 10% drawdown as a risk-reduction trigger based on cash-flow-adjusted executable equity, not a guaranteed loss floor; trigger cancels entries and targets zero exposure.
- (change) Second reviewer hardening added fenced single-writer semantics, exit precedence, candidate/horizon identity, bounded UNKNOWN recovery, UNSCORABLE controls, Evidence Specification, retention tiers, minimum invariants, and separated confirmed decisions from assumptions.
- (change) Closed final adversarial highs with testable hysteresis baseline, cross-family evidence governance, DRY RUN evidence semantics, concentration consistency, and migration acceptance/disposition contracts.
- (change) Reconciled incident and roadmap evidence into the final PRD: cutover manifest and regression fixtures, Indodax API v2 recovery contracts, transactional outbox/DLQ, runtime degradation, notification isolation, operational SLOs, and decision flip-rate diagnostics.
